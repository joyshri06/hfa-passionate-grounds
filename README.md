# ⚽ Hosur Football & Fitness Academy

A modern, premium, and fully responsive website developed for **Hosur Football & Fitness Academy (HFA)**.

HFA is a football academy based in Hosur, Tamil Nadu, established in **2018**, focused on developing football skills, fitness, discipline, and confidence among players.

## 🌟 Features

- Fully responsive design for Mobile, Tablet, and Desktop
- Modern premium sports academy UI
- Multi-page website architecture
- Smooth page transitions and animations
- Responsive navigation with mobile menu
- Custom desktop cursor interactions
- Animated statistics and counters
- Programs and training information
- Coaches section
- Gallery page
- Achievements page
- Events page
- Testimonials section
- Registration form
- FAQ section
- Contact page with WhatsApp integration
- Privacy Policy and Terms pages
- SEO-friendly structure
- Accessibility-focused design

## 📱 Responsive Design

The website is designed using a responsive approach to provide an optimal experience across different devices.

- 📱 Mobile
- 📱 Tablet
- 💻 Laptop
- 🖥️ Desktop

Layouts, typography, images, spacing, and components automatically adapt based on screen size.
